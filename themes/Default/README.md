# The Default theme

This theme is a derivative of the [MetroMumble skin](https://github.com/xPoke/MetroMumble). It retains the Lite and Dark variants and includes the
LuxMumble Discord Dark, Discord Light, Midnight AMOLED, and Neomorphic appearance presets. The macOS-specific Lite and Dark variants remain available.

This is the default theme that gets shipped with Mumble since version 1.3.0.
